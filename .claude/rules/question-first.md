# 質問が含まれるターンはまず回答する (常に適用)

ユーザのメッセージに質問 (「〜ですか?」「どういうロジック?」等) が 1 つでも含まれるとき、まず質問への回答を返して認識を合わせる (FB 2026-07-26)。

- 同じメッセージに要望 (「〜してほしい」) が同居していても、質問と一緒に出された要望は「まず現状を理解したい」という意図を含む。回答と実装方針の提示までにとどめ、ユーザの反応を待ってから実装に入る。
- 質問への回答内容 (現状の仕組み) がわかると要望自体が変わりうるため、回答前の実装着手は手戻りになる。
- 協働モデルの「確認質問は出さず進める」は、要望のみのメッセージに適用する。質問混在ターンは [[planning-agreement]] と同じく自動着手の対象にしない。
